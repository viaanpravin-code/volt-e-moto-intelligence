# VOLT E-Moto Intelligence

**Your electric ride. Your data. Your VOLT.**

VOLT E-Moto Intelligence is an Android companion app concept for electric motorcycle riders, built with Kotlin and Jetpack Compose.

> **Status: Early Beta — v0.1.0**
>
> This project is under active development. Features may be incomplete, inaccurate, or unstable.

## Features

- 📍 GPS-based ride tracking
- 🏁 Live speed and ride statistics
- 🔋 Estimated remaining range
- 🏍️ Electric motorcycle garage and bike database
- 🛡️ Security and ride information screens
- 🌑 OLED-black interface with red accents
- ✨ Animated Jetpack Compose UI

## Tech Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Android Location APIs

## Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or start an emulator.
5. Build and run the `app` configuration.

GPS functionality requires location permissions and a device with supported location services.

## Known Limitations

- GPS acquisition and speed updates need testing.
- Range estimates are preliminary and may not reflect actual riding conditions.
- Ride statistics and background behavior require further validation.
- Bugs and UI changes are expected during beta development.
